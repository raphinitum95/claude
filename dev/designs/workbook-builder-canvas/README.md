# Workbook Builder canvas: the source that generates every board

The design canvas (https://claude.ai/artifact/De4rnxZdsa3GBu88BCaSoV, private to the owner) was generated by these scripts.
When you build a screen, read the matching script instead of the canvas: it has the exact markup, tokens and sample data.

| Script | Boards |
|---|---|
| `common.py` | tokens (dark + light, from `src/regrunner/web/static/app.css`), icons, header with Run · Build · Results tabs, workbook rail |
| `data.py` + `round1_steps.json` | the 287-step Travelex example (blocks, gates, legacy rows, secrets) |
| `editor.py` | test editor: block map, cards, inspector, Excel grid, data drawer, problems, fix mode, add-step menu |
| `workbook.py` | workbook map, variable map |
| `record.py` | recording window: pill, hover card, Check this, which one, typed value → variable |
| `api.py` | API/XML editor, request import, scenario board |
| `dialogs.py` | new workbook, environments, template insert, duplicate, run blocked, fingerprint, run for real, file changed, history |
| `run.py` | earlier Run/Results states (PROD blocked, scenario live, failure detail cards) |
| `run2.py` | Run tab (one list + one plan, live batch) and Results tab (home, one test, compare) |

`python3 editor.py` (etc.) writes `.dc.html` files into `out/`. They are design boards, not app code: copy the markup and
styles into `web/static/js/views/...` using the app's own `html` helper and `app.css` classes.
